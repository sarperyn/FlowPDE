    Quickstart¶

    This guide walks you through training a flow matching model to solve the 2D Poisson equation.

    1. Generate Data¶

    FlowPDE integrates with APEBench to generate PDE datasets:

    from flowpde.datasets.apebench import APEBenchProvider

provider = APEBenchProvider()
train_ds, test_ds = provider.create_train_test(
    pde="poisson_2d",
    problem="forward",  # source → solution
    num_train=1000,
    num_test=200,
    cache=True,
)

    For inverse problems (solution → source), set problem="inverse".

    2. Define Model and Flow¶

    from flowpde.flows import FlowMatching
from flowpde.models import UNet

# Velocity field network
model = UNet(
    in_channels=1,
    out_channels=1,
    spatial_dim=2,
    spatial_size=32,
    base_channels=64,
)

# Flow matching with linear interpolation path
flow = FlowMatching(
    model=model,
    path="linear",          # linear interpolation x_t = (1-t)x_0 + t*x_1
    time_sampler="uniform", # t ~ U(0,1)
    coupling="independent", # standard pairing
    sigma=0.0,
)

    3. Train¶

    from flowpde.trainers import FlowTrainer

trainer = FlowTrainer(flow=flow, lr=1e-4)
trainer.train(
    data_loader=train_loader,
    epochs=100,
    save_dir="results/training/poisson_forward/",
)

    4. Sample Solutions¶

    from flowpde.solvers import ODEFlowSolver

solver = ODEFlowSolver(flow=flow, method="dopri5")
samples = solver.sample(
    condition=source_terms,  # conditioning input f
    n_steps=100,
)

    Using Config Files¶

    FlowPDE supports YAML-based configuration:

    python scripts/train_poisson_2d_flowmatching.py --config configs/training/unet_flow_poisson.yaml

    See configs/training/ for example configurations.
